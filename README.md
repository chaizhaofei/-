# COASTLINE V6.9 · 双桥云岭

当前为可试玩阶段包。稳定30帧目标尚未达到，新车型或视角首次使用仍有明显长帧风险；测试范围与未完成项目详见实测记录。

完整解压后双击「开始游戏.exe」。无需安装 Node，无需登录，资源全部在包内。打开的是可玩的游戏菜单；若浏览器没有自动出现，复制启动器显示的网址进入 Chrome 或 Edge。

朋友需要整个压缩包，请不要只发送 exe。开始游戏.cmd 是备用入口。

本版新增山脊「双桥云岭之旅」：选择云顶山脊、标准路线，点击对应旅行入口。推荐 COMET 拉力车，约6.16公里，目标3～5分钟。目的地可以继续自由探索，沿途也可在普通自由驾驶中访问。

修复比赛净成绩与名次规则：实际行驶时间＋每次救援3秒；完赛车辆按净成绩排序。新规则个人最佳另行分类，旧存档不删除。

玩法、规则、五图规划见「06.9使用与验收说明.md」；测试条件、实际结果与未验证项目见「06.9实测结果.md」。游戏菜单底部也可打开本版说明页。

旧版继续保留在原文件夹。本版不是五图全路线、全部车型的最终验收；请按实测记录理解完成范围。
